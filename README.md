# 🚀 ChronoSense - AI Study Builder

AI-Powered Dynamic Study Workload Rebalancer with integrated **Frontend (React + Vite)**, **Backend API (FastAPI)**, **ML Engine (Time-to-Mastery Predictor)**, and **CV Engine (Gemini Vision Auto-Grader)**.

---

## ⚡ Quick Start (Launch Everything in 1 Click)

Run the automated launcher script from the root directory:

### Option A: Double-Click or Command Prompt (`cmd`)
```cmd
start_all.bat
```

### Option B: PowerShell
```powershell
.\start_all.ps1
```

---

## 🌐 Active Services & Localhost URLs

When launched, the following services will be available:

* **Frontend UI Dashboard**: [`http://localhost:3000`](http://localhost:3000)
* **Main Backend API Docs (FastAPI)**: [`http://127.0.0.1:8001/docs`](http://127.0.0.1:8001/docs)
* **CV Engine API Docs (FastAPI)**: [`http://127.0.0.1:8002/docs`](http://127.0.0.1:8002/docs)

---

## 📁 Repository Structure

* `frontend/` - React + Vite + Tailwind CSS Web Application
* `backend/` - FastAPI Production Server (Integrates Supabase, ML Engine, and CV Grader)
* `ml_engine/` - Scikit-Learn TTM & Pacing Risk Predictor Model
* `cv_engine/` - Gemini Vision AI Handwritten Practice Sheet Auto-Grader
